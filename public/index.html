Workshop · Tokenomics

See what your AI habit actually costs.

One command. About ten seconds. It reads the session files already sitting on your laptop, prices every token at published API rates, and opens a report covering your last 30 days. By default nothing is uploaded, and nothing leaves the machine.

Terminal — tokens
curl -sL tokens.organizedai.vip/tokens.py | python3

macOS and Linux · uses the Python already installed with your system

Running it

01

Open Terminal

On a Mac, press ⌘ Space, type Terminal, press Enter. On Linux, open your usual terminal.

02

Copy the command

Use the Copy button above, or select the line and copy it by hand.

03

Paste it and press Enter

Your report opens in the browser as Organized Tokens: every model, every token, what each day cost, and which project burned it.

Before you paste a command from the internet

Read it first

The script is plain, dependency-free Python at tokens.organizedai.vip/tokens.py. Open it in a browser before you run it — it is about 400 readable lines.

What it reads

Claude Code transcripts in ~/.claude/projects and Codex sessions in ~/.codex/sessions. Token counts and model names only. Every file it touched is listed at the bottom of the report.

What it never does

No API keys, no credentials, no telemetry, no writes outside a single HTML file in your temp folder. Run it plain and it makes no network calls at all.

The one exception

At a workshop you can opt into a live leaderboard with --join. It prints the exact payload and waits for you to type join before anything uploads — counts and model names only, never prompts, paths, or project names. --leave deletes your row and your token.
