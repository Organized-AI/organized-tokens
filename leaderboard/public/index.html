Getting on the board
4 commands. No install beyond Python 3, which macOS and Linux already have.

Workshop code AIIC-2026 · script served from tokens.organizedai.vip

1

Get the script — one time, saved to a file:

curl -sL https://tokens.organizedai.vip/tokens.py -o tokens.py
2

Join with the name you want shown on the board:

python3 tokens.py --join AIIC-2026 --as "Your Name"

Prints the exact payload before sending anything. Read it, type join, press Enter. Anything else cancels — nothing is uploaded.

3

Start watching — this is what actually puts you on the board:

python3 tokens.py --watch

Leave it running in a terminal tab. Ctrl-C stops pushing — you stay listed until you leave.

4

Done for the day? Remove yourself:

python3 tokens.py --leave

Takes you off the board and deletes the local credential file.
