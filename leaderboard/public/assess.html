WHERE DO YOU USE AI CODING TOOLS?

1 · Collect from each environment

Run the collection prompt once on every environment whose local history should count. Each run creates one private JSON evidence bundle. Get each machine's id first:

TERMINAL
npx github:Organized-AI/ai-work-assessment#v8.0.0-organized.1 environment-id

2 · Bring the files together

Review the bundles, then move them into one folder on the computer where you will create the assessment. Nothing is uploaded.

TERMINAL
npx github:Organized-AI/ai-work-assessment#v8.0.0-organized.1 validate-bundle ./ai-work-evidence-*.json

3 · Create one assessment

Tested code validates the bundles, counts exact duplicate sessions once, and builds one profile.

TERMINAL
npx github:Organized-AI/ai-work-assessment#v8.0.0-organized.1 consolidate ./bundle-folder

05 / OPTIONAL SHARE IT TO THE BOARD

The report is yours either way.

Sharing adds the one thing a local run cannot do: a comparison against the aggregate, unnamed cohort, computed only after eight profiles exist, never from fewer. Type share and it also lists you on the talent directory, where people hiring for agentic work actually look.

Sharing is a separate command, gated on a typed word, from the machine that ran the assessment:

TERMINAL
python3 tokens.py --submit ~/Desktop/project-fit-*.html

Remove everything any time with python3 tokens.py --leave.
