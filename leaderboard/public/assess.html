WHERE DO YOU USE AI CODING TOOLS?

1 · Collect from each environment

Choose “Collect evidence” below, then run that prompt once on each environment whose history should count. Each run creates one private evidence bundle and obtains the machine’s opaque ID with:

TERMINAL
npx github:Organized-AI/ai-work-assessment#v8.0.1-organized.1 environment-id

2 · Bring the files together

Review the bundles, then move them into one folder on the computer where you will create the assessment. Nothing is uploaded.

The collection prompt validates each bundle using its exact filename. Keep the reviewed files together in a private folder.

3 · Create one assessment

Choose “Create final assessment” below. A local filter excludes unselected sources before your agent reads the bundles. Tested code validates the selected evidence and counts exact duplicate sessions once.

04 / FOR JOB SEEKERS BEFORE YOUR RESUME

2. Review and check your report

Open the HTML report your coding agent created. Check that it represents your work accurately and that private details are abstracted. Then choose that file below for a local structure and privacy check. The file is read in your browser and is never uploaded by this checker.

3. Continue to your resume

After the check, create your job seeker profile on Organized AI. Keep the assessment alongside your resume for conversations with employers. This step opens the job board; it does not attach or publish your assessment.

06 / OPTIONAL PUBLIC TALENT PROFILE

The report is yours either way.

If you have joined an Organized AI workshop board, you can submit your reviewed profile separately. Type share to list it publicly in the talent directory, or keep to store it privately. Either choice sends the structured assessment to Organized AI; raw transcripts are not submitted to Organized AI.

Download the current submission script first, then use the exact report filename:

TERMINAL
curl -fsSL https://tokens.organizedai.vip/tokens.py -o tokens.py
python3 tokens.py --submit /path/to/your-reviewed-report.html

Joining the workshop board shares your handle and aggregate activity counts publicly. It is separate from running the assessment. Remove your profile and workshop counts with python3 tokens.py --leave.

Cohort comparisons are not currently shown on this site. Sharing does not certify the underlying claims.
